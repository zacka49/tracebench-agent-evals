# AI assistance

This repository was initially scaffolded and implemented with substantial help from an AI
coding assistant. The assistant helped turn the experiment plan into Python code, tests,
documentation and local runs. The repository should be treated as a starting implementation
for the owner to study, extend and defend in review.

Before using it in an application, the owner should reproduce both configurations, inspect
several traces, explain the scorer and post-commit fault without assistance, and document
their own extensions. Experimental claims should come only from preserved run artifacts.
